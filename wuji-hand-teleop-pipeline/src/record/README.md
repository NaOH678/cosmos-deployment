# Deployment records

This directory contains model-specific deployment snapshots and debugging
findings. The maintained, model-neutral robot/cloud contract lives in
[`CLOUD_MODEL_INTEGRATION_GUIDE.md`](../wuji_data_pipeline/CLOUD_MODEL_INTEGRATION_GUIDE.md).

## PI0.5

- [`PI05_DROPPER_JOINT_DEPLOYMENT_NOTES.md`](pi/PI05_DROPPER_JOINT_DEPLOYMENT_NOTES.md):
  current Dropper Joint profile, safety limits, timing, and observed failures.
- [`CLOUD_DEPLOYMENT_HANDOFF.md`](pi/CLOUD_DEPLOYMENT_HANDOFF.md): historical
  sandwich EEF handoff and 50/40 timing record.

## Cosmos

- [`cosmos_4b_dropper_joint_deployment.md`](cosmos/cosmos_4b_dropper_joint_deployment.md):
  Cosmos 4B Dropper Joint profile, prefetch tuning, and discontinuity findings.

## LingBot-VA

- [`LBVA_DROPPER_JOINT_DEPLOYMENT_RECORD.md`](lbva/LBVA_DROPPER_JOINT_DEPLOYMENT_RECORD.md):
  Dropper Joint checkpoint, FDM timing, state history, and hardware findings.
- [`LINGBOT_VA_FDM_LOCAL.md`](lbva/LINGBOT_VA_FDM_LOCAL.md): robot-side FDM
  protocol and lifecycle contract.
